# 沉浸化工（Immersive Chemical）设计文档

## 1. 模组定位

沉浸化工是沉浸工程（Immersive Engineering）的化工附属模组，以沉浸原油（Immersive Petroleum）为前置，补足原油分馏之后的化工深加工内容。

核心体验是：

- 把原油、煤、盐水、空气和生物质等基础资源转化为可继续加工的化工原料；
- 使用大型、多方块、可观察的设备组织连续生产线；
- 通过温度、压力、催化剂、副产物和污染等有限而有意义的约束，体现“工业流程”，而不是增加大量单方块机器；
- 产出工程材料、橡胶、树脂、塑料、溶剂和生物医药中间体，为整合包提供新的材料和自动化目标。

本模组不尝试完整模拟现实化学。现实中的复杂反应以少量清晰的工艺阶段抽象，优先保证产线可读性、设备辨识度和与沉浸工程的风格一致。

## 2. 现实化工领域的取舍

现实化工可以归纳为以下方向，本模组按“能形成游戏产线”的价值选择内容：

| 领域 | 现实内容 | 在模组中的定位 |
| --- | --- | --- |
| 能源与原料加工 | 原油分馏、煤化工、天然气、焦化 | 前置与基础原料来源；分馏由沉浸原油提供，沉浸化工负责后续深加工 |
| 基础无机化工 | 氯碱、酸碱、氨、硫酸、氧气、氢气 | 首期基础化工，提供反应介质、处理剂和合成气原料 |
| 有机基础化工 | 烯烃、芳烃、醇、酮、醛、酸、溶剂 | 首期主线，把石油馏分转为可用于聚合和精细化工的单体 |
| 高分子与材料 | 树脂、塑料、合成橡胶、纤维、涂层 | 首期核心卖点，直接服务工程机器、工具和建筑材料 |
| 精细化工 | 染料、表面活性剂、胶黏剂、添加剂 | 第二阶段，用于染色、处理、强化和跨模组配方 |
| 化肥与农业化学 | 氨、硝酸盐、尿素、肥料 | 可选扩展，连接农业和资源循环玩法 |
| 制药与生物化工 | 中间体、培养基、消毒剂、药物载体 | 后续联动生物医药模组；沉浸化工只提供通用化工平台和中间体 |
| 环境与公用工程 | 废气、废水、回收、尾渣、冷却水 | 作为轻量约束和优化方向，不做强制生存惩罚 |

首期重点是“石油/煤等原料 -> 基础化学品 -> 树脂与橡胶 -> 工程材料”。制药、化肥和完整环保系统留出接口，避免首版内容失控。

## 3. 内容总览

### 3.1 Items

物品按用途分组，不要求每个现实化学品都单独占用一个物品：

- **催化剂与工艺介质**：通用催化剂、酸性催化剂、碱性催化剂、聚合引发剂、硫化剂、吸附剂、干燥剂；可设计为可回收或有损耗的工艺组件。
- **固体中间体**：酚、醛类中间体、单体颗粒、树脂颗粒、炭黑、填料、硫磺、工业盐、工业级晶体。
- **高分子材料**：酚醛树脂、通用塑料颗粒、工程塑料颗粒、合成橡胶、硫化橡胶、纤维和薄膜。
- **工程制品**：橡胶板、密封件、绝缘件、塑料板、耐化学涂层、复合材料板。它们优先服务沉浸工程设备和管线，而不是单纯增加装饰方块。
- **质量与安全用品**：过滤芯、废催化剂、污染固体、检修工具。用于表达维护和副产物处理，可选而不应成为重复点击负担。

### 3.2 Fluids

流体是产线的主要连接方式。建议使用统一的流体标签，允许其他模组提供等价流体：

- **原料流体**：原油馏分、轻烃、重油、煤焦油、盐水、工业水、冷却水。
- **基础化工流体**：酸液、碱液、氯气、氢气、氧气、合成气、氨水、醇类、酮类、通用溶剂。
- **聚合与处理流体**：单体溶液、乳液、树脂溶液、增塑剂、硫化介质、清洗液。
- **副产物流体**：废气、含酸废水、含碱废水、含油废水、稀释尾液。副产物应优先可回收或净化，避免无意义的“垃圾流体”。

具体命名和材质在实现阶段统一通过 Forge 流体标签与配方条件管理，减少对某一个版本或前置模组的硬编码。

### 3.3 Blocks

- 多方块机器的结构方块、控制器、端口、观察窗、加热器、冷凝器、泵和阀门；
- 化工管线、耐腐蚀管线、流体储罐、气体储罐、缓冲罐、废液池；
- 催化剂架、过滤器、冷却塔、火炬塔、实验台和质量检测台；
- 少量可直接用于建筑的工业材料方块，如树脂板、橡胶板、涂层钢板和绝缘板。

方块的视觉语言沿用沉浸工程：钢结构、铜制管线、玻璃观察窗、明显的进出料口和可读的状态灯。

### 3.4 Entities

首期不新增生物或复杂移动实体。可选的轻量实体包括：

- 火炬塔的火焰/烟雾效果实体；
- 泄漏时的气体云或蒸汽云（短生命周期、可关闭）；
- 运输中的罐车/集装箱展示实体（若后续需要和物流模组联动）。

### 3.5 Effects

效果应服务于设备状态和安全反馈，而不是增加惩罚性生存压力：

- 有毒/窒息/灼伤等短时状态，用于错误操作或严重泄漏；
- 防护服、滤毒面具等装备提供抗性；
- 正常产线不应要求玩家持续佩戴装备，安全系统应允许通过通风、冷却和正确配方避免事故。

## 4. 代表性多方块机器

下表是首期建议加入的机器。每台机器都应有独立外观、明确的物流接口和至少一种“看得见”的运行反馈。

| 机器 | 主要职责 | 代表性输入/输出 | 特色与优先级 |
| --- | --- | --- | --- |
| **化工反应釜** | 液相反应、酸碱处理、酚醛缩合、溶剂合成 | 基础化工流体、催化剂 -> 中间体流体/树脂溶液 | 首期核心；支持温度、压力、搅拌和催化剂槽 |
| **裂解炉/热解炉** | 将重质馏分、煤焦油或生物质转为轻质单体和合成气 | 重油/煤焦油/生物质 -> 烯烃、芳烃、焦炭、废气 | 首期核心；高温、燃料和耐热结构是主要约束 |
| **气体分离塔** | 吸收、解吸、干燥和分离混合气 | 合成气/空气/氯碱尾气 -> 氢气、氧气、氯气、废气 | 首期核心；体现气体储存、压缩和尾气回收 |
| **聚合反应器** | 乳液、悬浮或本体聚合 | 单体、引发剂、溶剂 -> 树脂颗粒、塑料颗粒、乳液 | 首期核心；批次时间较长，支持催化剂和温度窗口 |
| **硫化压机** | 橡胶硫化、板材和密封件成型 | 生橡胶、硫化剂、模具 -> 硫化橡胶制品 | 首期核心；压力和加热同时存在，产出直接可见的工程件 |
| **蒸发结晶器** | 浓缩溶液并回收固体盐/晶体 | 盐水、废液、冷却水 -> 工业盐、晶体、浓缩尾液 | 首期或早期扩展；承担副产物处理和资源回收 |
| **电解槽组** | 电解盐水或水，制备氢气、氧气、氯碱 | 盐水/水、电力 -> 氢气、氧气、碱液、氯气 | 首期核心；把电力转化为化工原料，适合沉浸工程风格 |
| **精馏/吸收塔** | 对反应混合物进行精制、回收溶剂和分离副产物 | 混合液/气体 -> 高纯产品、回收溶剂、尾液 | 第二阶段；与沉浸原油分馏塔形成“前端分馏、后端精制”的区别 |
| **涂布与复合线** | 将树脂、橡胶或涂层加工成板材、膜和复合材料 | 树脂/橡胶/纤维/填料 -> 工程板材、绝缘层 | 第二阶段；偏制造端，可作为多方块连续线而非单台机器 |

机器不必全部在首个版本实现。首期推荐“化工反应釜、裂解炉、气体分离塔、聚合反应器、硫化压机、电解槽组”六台，已经足以组成完整的化工主线。

## 5. 建议的进度与产线

### 阶段 A：前置接入与基础化工

- 检测沉浸原油的原油、馏分、焦油和燃料流体；
- 使用工业水、盐水、空气和煤焦油建立最初的反应介质；
- 解锁化工管线、储罐、电解槽组和基础反应釜；
- 目标是让玩家从“只有燃料”进入“能生产化工中间体”。

### 阶段 B：近代化工与高分子材料

- 通过裂解炉和反应釜获得酚、醛类中间体、单体和硫化剂；
- 聚合反应器生产酚醛树脂、通用塑料和生橡胶；
- 硫化压机生产硫化橡胶、密封件、绝缘件和橡胶板；
- 目标是形成第一条有辨识度的“石油 -> 树脂/橡胶 -> 工程部件”产线。

### 阶段 C：现代化工与精细加工

- 增加气体分离、精馏/吸收、溶剂回收和高纯产品；
- 引入工程塑料、复合材料、表面活性剂、胶黏剂和涂层；
- 通过副产物回收降低能耗与原料消耗，鼓励优化而不是强制处理每一滴废液。

### 阶段 D：生物医药联动接口

- 提供通用溶剂、消毒剂、培养基组分、缓冲液、聚合物载体和包装材料；
- 允许生物医药模组通过标签或兼容配方调用这些中间体；
- 沉浸化工不直接实现完整药物树，把重点放在上游原料、设备和工业包装。

## 6. 模组可以提供的用途

### 对沉浸工程本体

- 橡胶板、密封件、绝缘件、耐腐蚀涂层，作为高阶机器、线缆、变压器和流体设备的材料升级；
- 化工储罐、耐压管线、冷却塔和火炬塔，扩展大型工业基地的建筑表达；
- 树脂和塑料用于更轻、更耐腐蚀的工程组件，形成钢铁之外的材料路线。

### 对整合包

- 提供跨模组通用的溶剂、酸碱、气体、塑料、橡胶和催化剂标签；
- 为农业、科技、物流、能源和生物医药模组提供上游材料，而不是重复它们的终端产品；
- 提供一条资源消耗大、产线长但产物通用的中后期自动化目标。

### 对玩家基地与玩法

- 大型化工厂的视觉建造：塔器、储罐、管廊、火炬塔和观察窗都有实际功能；
- 通过缓冲罐、回收回路、冷却和副产物处理优化工厂吞吐量；
- 事故和安全作为可选的沉浸感系统，服务于建造与规划，而不是随机摧毁基地。

## 7. 设计原则与边界

1. **产线优先，配方从简**：文档先确定原料类别、工艺阶段和用途；具体数量、时间和能耗在实现与测试阶段调整。
2. **多方块优先**：只有当设备能表达新的空间布局、物流关系或运行状态时，才增加新的多方块机器。
3. **前置不重复**：原油分馏沿用沉浸原油；沉浸化工负责分馏产物的裂解、合成、聚合和材料加工。
4. **副产物可管理**：副产物应能回收、净化、燃烧或转化，避免不可处理的永久堵塞。
5. **现实感服务于可玩性**：保留温度、压力、催化剂和纯度等少数关键变量，不引入需要查表才能玩的化学模拟。
6. **兼容优先**：物品和流体尽量使用标签、数据驱动配方和可选依赖；没有沉浸原油时，模组应明确提示而不是静默失效。
7. **安全可读**：机器界面、状态灯、声音和粒子效果要能说明“缺什么、为什么停、如何恢复”。

## 8. 首期范围（MVP）

首个可玩的版本建议包含：

- 6 台核心多方块机器：化工反应釜、裂解炉、气体分离塔、聚合反应器、硫化压机、电解槽组；
- 约 4 类基础化工流体、4 类中间体流体、4 类副产物/处理流体；
- 酚醛树脂、通用塑料、生橡胶、硫化橡胶、催化剂、硫化剂、密封件和绝缘件等关键物品；
- 化工管线、储罐、冷却/通风组件和基础安全反馈；
- 沉浸原油兼容层、JEI/配方查看支持、基础数据包标签和配置项；
- 一条完整可运行的主线：沉浸原油馏分 -> 基础单体/中间体 -> 树脂或橡胶 -> 沉浸工程升级部件。

精馏/吸收塔、复合材料线、污染系统、化肥和生物医药专用中间体放入后续版本，待首期产线验证后再扩展。

## 9. 后续待定问题

- 是否使用统一的“压力等级”而不是为每种气体建立真实压力单位；
- 催化剂是独立物品耐久、机器内置槽位，还是两者结合；
- 事故系统是否默认开启，以及对多人服务器的性能和可见性影响；
- 与沉浸原油不同版本的流体名称、分馏塔接口和燃料单位如何兼容；
- 生物医药联动采用公开标签、可选 compat 模组，还是由对方模组提供配方。

## 11. 素材库的使用规则

1. **先选产线，再选名词**：只有能连接到一条有意义的输入/输出链，物质才进入实装候选；素材库中的名词不自动等于注册内容。
2. **同类物质合并抽象**：低阶版本可以使用“轻烃”“芳烃混合物”“通用溶剂”“酸液”等集合名，等内容成熟后再拆分为具体化学品。
3. **状态决定玩法**：气体体现压缩、储存和泄漏；液体体现泵送、混合和分层；固体体现仓储、批次和成型。
4. **现实与幻想分层**：现实化学品负责建立可信的工业骨架，Minecraft 特色物质负责提供世界观、稀有度和终局目标。
5. **危险品抽象处理**：爆炸性、剧毒性和放射性物质只保留游戏需要的风险标签，不在文档中展开现实制备步骤。
6. **所有条目都应有用途候选**：材料升级、机器建造、燃料、催化剂、跨模组中间体、建筑表现或任务奖励至少命中其中一项。
